# Sensorik

In diesem Ordner befindet sich die Sensorik des Smart-Gardening-Projekts.

Die Sensorstation wird mit zwei unterschiedlichen Mikrocontrollern umgesetzt:

- MKR WAN 1310 mit C/C++
- ESP32 mit MicroPython

Im jeweiligen Unterordner befinden sich die Programme, Sensorbeispiele und die dazugehörige Dokumentation.

Aktuell liegt der Schwerpunkt auf dem MKR WAN 1310. Die Umsetzung mit dem ESP32 wird später ergänzt.
