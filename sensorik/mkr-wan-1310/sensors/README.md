# Sensoren

In diesem Ordner befinden sich die Sensoren, die im Smart-Gardening-Projekt verwendet werden.

Für jeden Sensor gibt es einen eigenen Unterordner mit:

- einer kurzen Beschreibung
- Informationen zum Anschluss
- verwendeten Bibliotheken
- wichtigen Funktionen
- Beispielcode zum Testen

Einige Sensoren sind bereits integriert und getestet. Andere wurden bestellt und werden ergänzt, sobald sie verfügbar sind.
